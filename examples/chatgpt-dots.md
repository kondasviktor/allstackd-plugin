# ChatGPT (custom connector / Developer Mode)

The public directory listing is parked. Until it is live, add AllStackd as a custom connector:

1. ChatGPT → Settings → Connectors → Advanced → enable **Developer mode**.
2. Create a connector with MCP server URL `https://allstackd.com/mcp` and authentication **OAuth**.
3. Sign in with your AllStackd account when prompted.

Prompts to try:

- "List my agent inboxes and summarize new threads."
- "Show my SES health."
- "Draft a reply to the latest thread in support@ for my approval."

Replies are never sent until you approve them in AllStackd.
